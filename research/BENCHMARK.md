# Initial benchmark methodology

Run cargo run --release --locked --example bench. Fixed nonsecret 32-byte key and repeated-byte payloads. Sizes: 64, 4096, 1048576 bytes. 200 operations for small sizes, 12 for 1 MiB. Encryption uses unique counter-generated public test nonces per mode; decryption repeatedly verifies the same envelope. Timing includes allocation, header handling and cryptographic operations, but excludes key delivery and randomness. No hardware feature flags explicitly enabled; compiler default target and library runtime detection apply. No pinning, isolation or warm-up, one run only. This is exploratory, not a stable benchmark. MiB means 1,048,576 bytes. Do not compare it to network KEM/signature operations or infer security from it. Future runs need medians, variance, machine class, portable and accelerated variants, browser paths and memory measurements.
